## 样例

**原题**（os48-2）：设 k=3，求极限 lim(x→∞) e^x/x^k，答案 ∞
**一问**：设 k=3，求极限 lim(x→-∞) e^x/x^k　（改了 趋向点：∞ → -∞）
正确答案 0；答 ∞ → 漏看了「趋向点」从 ∞ 改成 -∞，答的还是原题结果

**原题**（os48-18）：设 n=3，求极限 lim(x→0) ((1+x)^n-1)/x，答案 n
**一问**：设 n=4，求极限 lim(x→0) ((x + 1)^n - 1)/x　（改了 参数 n：3 → 4）
正确答案 4；答 3 → 漏看了「参数 n」从 3 改成 4，答的还是原题结果；答 -4 → 符号弄反了；答 1/4 → 上下颠倒了（算成了倒数）

**原题**（os48-30）：求极限 lim(x→0+) x ln(x^4)，答案 0
**一问**：求极限 lim(x→2+) x*ln(x^4)　（改了 趋向点：0 → 2）
正确答案 2*ln(16)；答 0 → 漏看了「趋向点」从 0 改成 2，答的还是原题结果；答 -2*ln(16) → 符号弄反了；答 1/(2*ln(16)) → 上下颠倒了（算成了倒数）

**原题**（os48-42）：求极限 lim(x→0) x sin(1/x)，答案 0

正确答案 1；答 0 → 漏看了「趋向点」从 0 改成 ∞，答的还是原题结果；答 -1 → 符号弄反了

**原题**（os23-3）：求极限 lim(x→-2) sqrt(x^2-6x+3)，答案 sqrt(19)
**一问**：求极限 lim(x→0) sqrt(x^2 - 6x + 3)　（改了 趋向点：-2 → 0）

**原题**（os23-15）：求极限 lim(t→9) (t-9)/(sqrt(t)-3)，答案 6
