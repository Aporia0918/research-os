# 反事实一问 · 高数极限原型

学生刚看完一道题和答案，以为懂了。把题目和答案发进来，几秒内拿到一道**只改了一个关键条件**的变式；
变式的答案由求解器核过。学生作答，答错时判断是「漏看了改动的那个条件」还是别的错。

和主应用、安卓端、master 都无关，单独一个文件夹，只依赖 `sympy`。

## 流程

1. **读题**：题面 → 结构（式子、趋向点、单双侧、参数）。打字题面用规则读（`cfq/text.py`）；
   截图和自由描述用模型读（`cfq/model.py`，接口相同，等钥匙到位再测）。
2. **锚定**：sympy 求极限，再在趋向点附近用 60 位精度数值逼近复核，两者一致才算核验过。
   题目给的答案对不上就不出变式。
3. **找反事实**：只改一处——趋向点、单侧/双侧、参数取值、指数、系数、常数项、减号、底数。
   留下答案变了且核验过的，按「漏看条件能否区分」「要不要真算」「形式变了方法不能照搬」排序，取前三（改法各不相同）。
4. **备错答**：原题答案（漏看条件）、照搬洛必达、直接代入、左右弄反、符号反、倒数。学生答案用等价比对归类。
5. **改写回读**：变式写回题面，再读一遍，核对和变式结构一致。

## 用法

```
pip install sympy
python3 -m cfq "求极限 lim(x→3) (x^2-9)/(x-3)" 6 --student 6
python3 eval.py            # 跑 data/limits.jsonl，写 report.md 和 results.json
```

换成真实截图题：把 `data/limits.jsonl` 换成新文件（同字段），或把 `run(..., read=ModelReader())` 接上模型读题。
模型读题需要 `CFQ_API_KEY`，费用累计超过 50 元自动停。

## 题目来源

OpenStax《Calculus Volume 1》2.3、4.8 节习题（LibreTexts 版，CC BY-NC-SA 4.0），每题的链接和题号在 `data/limits.jsonl`。
答案取原页；带参数的题本测试给参数取了具体值，已在 `note` 字段注明。另有 3 条人为改错的答案，只用来测锚定。
